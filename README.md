# 二胡音准练习（纯前端调音器）

打开即用，无需安装：**https://minichao9901.github.io/my_pages/**

iPhone 上建议用 **Safari** 打开（微信/QQ 内置浏览器拿不到麦克风权限），
然后「分享 → 添加到主屏幕」当作 App 用。

## 它是什么

一个**给二胡用的音准练习面板**：竖排的指板图 + 实时箭头，拉响一个音就能
一眼看出实际音高落在哪个音位上、偏了多少音分。

- **指板面板**：内弦 / 外弦两列，按半音等比排布（全音间距是半音的两倍，
  所以 3→4、7→1̇ 这类半音会明显挨得更近——真实指距就是这样）
- **三个把位**：以 1 和 5 为起点，每 5 个音位一个把位
- **六个调**：1=D / G / F / C / A / bB，简谱数字随调重算
- **音准基准 A4 可调**（440~444）：跟录音或乐团练时，录音的音高标准常常
  不是 440（实测某些出版录音在 441.6 / 443.7），不校准的话整首都会显示偏高
- **点面板上的圆圈会发声**：不听麦克风也能用，方便听音找把位
- **音阶练习**：低 2 个八度，上下行来回，速度 60–140 BPM 可调
- **节拍器**：与音阶共用速度，咔哒声与音阶每个音自动对齐
- **练习计时**：1 / 3 / 5 分钟，到点响六声并提示

## 技术说明

单文件 HTML，全部内联，零外部依赖、零构建、零后端。
音高检测用 YIN 算法（基频检测的中位误差 <0.2 音分），
全部计算在手机本地完成——**麦克风音频不会离开设备**。
