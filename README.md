# 弦外之音 · 二胡调音与练习

打开即用：**[minichao9901.github.io/erhu](https://minichao9901.github.io/erhu/)**

面向手机竖屏的单文件二胡调音器。所有屏幕统一采用居中的单列竖屏工作区：完整双弦指板占据主画面，顶部用紧凑读数条显示音高与音分，底部保留检测范围和收音按钮。手机竖屏下指板约占调音工作区的 68%–80%；桌面也不会恢复左右分栏。调音、练习、设置、指南各占一页，无需上下滚动。

## 功能

- **双弦同音显示**：例如 A4 同时标出内弦第五个音位与外弦空弦，双箭头、双目标圈、双弦位置卡片同步更新。也可以锁定一根弦。
- **准确的变化音读数**：按实际十二平均律半音计算音分，不将变化音误判成偏离相邻音阶。指板仅高亮确实存在的音位。
- **全屏**：右上角一键切换；桌面可按 F / Esc。不支持网页全屏的浏览器会提示并启用专注布局，手机也可以添加到主屏幕。
- **指板试听**：点击任意音位播放参考音，再次点击停止。麦克风音频仅在设备上分析，不录制、不上传。
- **六个调**：D / G / F / C / A / ♭B，指板简谱随调更新；内外弦始终定为 D4 / A4。
- **A4 校准**：440–444 Hz，保存在当前设备。
- **练习**：往复音阶、60–140 BPM 节拍器、每音半拍/一拍/两拍、1/3/5 分钟计时。音阶开始后自动返回大指板，可在指板顶部停止。

同一频率在两根弦上都有对应音位时，网页会显示两个可能位置；麦克风无法仅凭相同音高确定实际发声的琴弦。本工具检测单一基频，不是两个不同音高的复音分离器。

## 检测与验证

使用 YIN 归一化差分寻找周期，再在原始差分曲线上插值，减少高音处归一化带来的偏差。复用工作缓冲区，避免每帧分配数组；保留高可信度换音即时响应、低可信度连续确认与三帧中值平滑。

在 44.1 / 48 / 96 kHz、D4–A6、三种起始相位、纯音与强二次谐波组成的 576 个合成样本中，最大误差约 **0.24 音分**。这是可重复的算法测试结果，不代表手机麦克风和真实演奏环境下的绝对误差。

```sh
node test/run-all.js
```

零依赖，Node 18+。包含 DSP、双弦位置、音阶/节拍器/计时器、分页、全屏与谱面回归。浏览器布局已检查 320×568、375×667、390×844、430×932、844×390 与 1280×720。

## 本地运行与发布

```sh
python -m http.server 4173 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4173/`。线上收音需要 HTTPS；GitHub Pages 已提供 HTTPS。

GitHub Pages 当前从 `gh-pages` 分支的根目录发布。发布时先通过测试，再将包含最新 `index.html` 的提交推送到 `main` 和 `gh-pages`。没有构建步骤、外部字体、CDN 或后端服务。
