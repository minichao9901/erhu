怎么用（30 秒上手）
  • 手机离琴 20–40 cm，别贴在琴筒上（会爆音）。
  • 先点「内弦 D」参考音听准，再拉内弦，看指针：偏低就慢慢拧紧琴轴，偏高就放松。
  • 指针进入中间绿色区（±5 音分）即音准达标，数字和音名都会变绿。
  • 内弦调完再调外弦 A4。两弦互相影响，建议来回复查 1–2 遍。
  • 环境吵、或两弦共振串音时，用「内弦 D4 / 外弦 A4」固定模式，识别更稳。
  • 拉弓要平稳持续，短促点一下就抬弓会让读数跳。
打不开麦克风？常见原因

iPhone 必须满足两个条件才能用麦克风：HTTPS 网页 + 你亲手点「允许」。

  • 页面不是 https:// 开头 → Safari 会直接拒绝，没有任何弹窗。请用 HTTPS 地址打开。
  • 点过「不允许」→ 到 设置 → Safari 浏览器 → 麦克风 改成「允许」，或点地址栏左侧 aA → 网站设置 → 麦克风 → 允许，然后刷新页面。
  • 用微信 / QQ / 抖音内置浏览器打开 → 右上角「···」→ 在 Safari 中打开（微信内置内核拿不到麦克风）。
  • 提示被占用 → 关掉正在录音/通话的 App（微信语音、录音机、视频会议）。
  • 无障碍：先点一次「开始调音」是必须的，iOS 不允许网页自动开麦，做不到零授权。
